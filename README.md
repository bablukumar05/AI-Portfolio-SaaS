# 🚀 AI Portfolio SaaS - Industry Grade Developer Hub

An enterprise-ready MERN stack application designed for developers and creatives to showcase their work using AI-powered automation. Featuring dynamic portfolio building, AI blog generation, and deep analytics.

## ✨ Key Features

- **🤖 AI Co-pilot**: Generate professional blog posts and project descriptions using OpenAI.
- **🎨 Dynamic Builder**: Real-time portfolio editor with drag-and-drop capabilities.
- **📊 Advanced Analytics**: Track views, engagement, and visitor demographics with interactive charts.
- **🔐 Enterprise Security**: Role-based access control, JWT authentication, and secure payment processing.
- **🌗 Dark Mode & Themes**: Multiple premium themes (Cyberpunk, Minimal, Sunset) with glassmorphism UI.
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.

## 🛠️ Tech Stack

- **Frontend**: React (Vite), Tailwind CSS, Framer Motion, Lucide React, Recharts.
- **Backend**: Node.js, Express, MongoDB (Mongoose), Socket.io.
- **AI**: OpenAI API integration.
- **Payments**: Stripe subscription management.
- **DevOps**: GitHub Actions (CI/CD), Winston Logger, Helmet Security.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas account
- OpenAI API Key

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/ai-portfolio-saas.git
   cd ai-portfolio-saas
   ```

2. **Server Setup**
   ```bash
   cd server
   cp .env.example .env
   # Update .env with your credentials
   npm install
   npm run dev
   ```

3. **Client Setup**
   ```bash
   cd ../client
   npm install
   npm run dev
   ```
